# GitLab 工作台

在 DSH 左侧栏加入一个 **GitLab** 入口，打开一个全屏工作台，把多个自托管 GitLab 实例的日常操作集中到会话旁边。适配 GitLab Self-Managed 17.x（REST API v4）。

## 功能

- **多实例**：每个实例保存独立的地址、TLS 设置和个人访问令牌；顶栏切换，项目列表与流水线随之切换。
- **项目栏**：左侧常驻项目列表，搜索与切换都不离开当前视图。
- **概览**：开放议题/合并请求、Star/Fork、最近流水线、分支与提交。
- **流水线**：列表 + 阶段时间线 + 作业、失败作业日志末尾、重试/取消流水线与作业。
- **合并请求与议题**：列表与详情，附在 GitLab 打开的链接。
- **文件**：仓库目录树与文本文件查看。

## 认证

在「实例与令牌」为每个实例填写个人访问令牌：

- `read_api`：只读视图；
- `api`：额外允许重试/取消流水线与作业。

令牌只保存在 DSH Host 的凭据服务里（`gitlab-workbench/<实例 id>`），浏览器端不会收到令牌值；所有 GitLab 请求由 Host 代理发出。

## 自托管与证书

- 实例地址填根地址（例如 `https://gitlab.acme.example.com`），调用会拼上 `/api/v4`。
- 自签证书或企业 CA：把 CA 证书 PEM 粘到「企业 CA 证书」；仅在明确风险时关闭「校验 TLS 证书」。
- 实例部署在子路径下（如 `https://host/gitlab`）同样可用。

## 限制

- 以只读浏览为主；写操作目前只有流水线/作业的重试与取消。
- 项目工作台以当前选中项目为范围，跨项目收件箱尚未提供。
- 大文件与二进制文件不在页面内渲染；作业日志只取末尾约 200 KB。

## 工程结构

Host 半（`src/host`）负责令牌、实例清单与 GitLab REST 调用；Client 半（`src/client`）按 `views/` 拆分面板、项目、概览、流水线、合并请求、议题、文件与设置。`npm run build` 产出 `dist/`（tsc 编译 Host，esbuild 打包 Client，React 外置）。
